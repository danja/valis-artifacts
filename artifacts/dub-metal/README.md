# dub-metal (working title)

C Phrygian Dominant, 85 bpm, 3:23. Dub reggae foundations (a heavy electric bass, a one-drop kit, sparse offbeat organ
stabs into a dotted-eighth echo) with industrial metal-bashing on top and a low bell in the breakdown. Brief:
`../../sources/dub-metal-prompt.md`.

* `mixes/dub-metal-v3.wav`: the latest mix, -14 LUFS. v1 and v2 are kept to compare. Measured, not heard.
* `midi/`: bass, kit, stabs, metal, bell.
* `wavs/`: the stems and the two echo returns.
* `docs/report.md`: how it was made, what worked, what did not.
* Made by `../../scripts/dub-metal/track.py` with circuits from the Valis repository.
