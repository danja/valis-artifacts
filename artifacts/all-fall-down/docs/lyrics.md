# All Fall Down: lyrics for a speech synth

A short, broken text for a speech synthesiser. The voice starts calm, as if reciting a rhyme to a child, and comes apart as the track
goes on: lines repeat, words stick, the rhymes run into each other and lose their order, and at the end the voice is calm again but
has forgotten how the rhyme goes. Every line is plain text with no markup, so any synth can read it.

The fragments are traditional nursery rhymes ("Ring a Ring o' Roses", "London Bridge Is Falling Down", "Humpty Dumpty", "Twinkle,
Twinkle, Little Star", "Rock-a-bye Baby"), which are out of copyright. Everything else is new. A bar at 140 bpm is 1.714 seconds, so
a line of eight words fits in about two bars if it is read at a steady pace.

Bar numbers are from the start of the section in `song.ttl`: intro 16 bars, build1 8, drop1 16, break 16, build2 8, drop2 24, outro 16.
