# Repo Layout

* README.md should list the artifacts with links & short descriptions, and have a preamble giving an very brief overview of Valis with a link to https://github.com/valis and a poscript linking to my (Danny Ayers's) blog - https://danny.ayers.name and current music projects page, https://strandz.it
* docs/ : general documentation
* sources/[track title]/ : any source material use in the construction of the artifacts, eg. midi files, requirement prompts etc.
* artifacts/[track title]/README.md : a description of what's here for this track
* artifacts/[track title]/docs/ : track-specific documentation, plus lyrics and record sleeve images
* artifacts/[track title]/wavs/ : wav rendering
* artifacts/[track title]/midi/ : midi files
* artifacts/[track title]/mixes/ : mixdowns of the track
* scripts/ : decide on a case-by-case basis, possibly put under subdir [track title]/
